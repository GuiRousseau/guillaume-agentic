# AI in this Project

This repository uses an agentic architecture for intelligent orchestration.

## Purpose

- Define agents that coordinate skills
- Keep reusable skills separate from agent logic
- Use rule definitions for safe, predictable behavior

## Folder layout

- `.agent/agents/` - Agent definitions and orchestrators
- `.agent/skills/` - Reusable skills and capability modules
- `.agent/rules/` - Policy or rule sets for agent behavior
